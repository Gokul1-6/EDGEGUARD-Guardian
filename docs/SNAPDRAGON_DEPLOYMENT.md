# Snapdragon deployment plan

1. Validate the application on the actual Snapdragon HP laptop.
2. Select a compact local AI model for event classification/summarization.
3. Export to a supported format such as ONNX where appropriate.
4. Evaluate/compile using Qualcomm AI Hub and supported Snapdragon runtimes.
5. Benchmark CPU/GPU/NPU behavior on the target device.
6. Record measured latency, memory, throughput and power behavior.
7. Use only measured numbers in the competition presentation.

No unverified Snapdragon benchmark numbers are included in this repository.
